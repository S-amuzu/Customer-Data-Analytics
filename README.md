# Customer Segmentation Analysis – Retail Banking

## Overview
Exploratory data analysis and unsupervised clustering of retail banking 
customer data to identify distinct customer segments based on behavioural 
and financial attributes.

**Note:** The original dataset is confidential and has been excluded from this repository. Analysis is provided for portfolio purposes only.

## Analysis Performed
- Data cleaning and preprocessing
- - Exploratory data analysis (EDA)
- Clustering Analysis

## Purpose
Identifying meaningful customer groups to support targeted business 
decisions in a retail banking context.
